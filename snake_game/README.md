## Project Description

This project is a classic Snake game built using the Python Arcade framework.  
The game demonstrates event-driven programming, real-time graphics rendering, keyboard input handling, collision detection, and dynamic difficulty scaling.

The player controls a snake that grows in length as it consumes food.  
The game ends if the snake collides with the wall or with itself.

Difficulty increases as the player scores points.
